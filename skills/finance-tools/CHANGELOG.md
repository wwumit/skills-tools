# Finance Tools — 更新日志

## [1.1.0] - 2026-07-19

### 新增
- **category 命令**: 分类汇总 — 按类别分组展示收支，含ASCII条形图和占比
- **budget 命令**: 预算 vs 实际对比 — 按类别对比差异和执行率
- **yoy 命令**: 同比/环比增长分析 — MoM/YoY 双维度增长率 + 年度汇总
- **forecast 命令**: 趋势预测 — 三种模型(线性回归 / 移动平均 / 加权移动平均)，含R²拟合优度

### 变更
- **analyze 命令**: 新增分位数(P25/P75)输出；有日期列时自动显示月度净额
- **ratios 命令**: 大幅扩充 — 新增毛利率、净利率、资产负债率、ROE、ROA、ROI识别和计算
- **trend 命令**: 新增移动平均线(MA)、同比(YoY)增长率
- 统一的金额列识别，支持逗号分隔数字和空格
