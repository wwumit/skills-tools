# 🏋️ Fitness Daily — 30 岁青年健身自律打卡

一位 30 岁青年把坚持多年的每日健身习惯固化为打卡清单并**共享**出来。
四组 15 项：身体活动 / 营养与恢复 / 心理与习惯 / 纪律底线。
勾选今日完成项 → 完成率 → 状态判定 → 下周重点建议。

> **类别**：纪律类 · 非认证众包
> 本 Skill 代表共享者个人的好习惯 / 好做法，经内容审核后上线，仅供参考，**不构成医疗、营养等专业建议**。

## 核心功能

- **check** — 今日打卡（交互式逐项勾选，或 `--done f1,f3,f5` 直接传）
- **report** — 生成报告（完成率 / 分组明细 / 状态 / 下周重点建议）
- **trend** — 多日完成率趋势追踪
- **summary** — 一句话摘要

## 四组十五项

| 组 | 项 | 示例 |
|------|------|------|
| 身体活动 | f1–f3 | 30 分钟中高强度运动 / 步数≥8000 / 拉伸 10 分钟 |
| 营养与恢复 | f4–f8 | 饮水≥2升 / 蛋白质达标 / 蔬菜占一半 / 无深夜进食 / 睡眠 7–9 小时 |
| 心理与习惯 | f9–f12 | 冥想 5 分钟 / 屏幕时间≤2小时 / 健康日志 / 阅读 15 分钟 |
| 纪律底线 | f13–f15 | 未饮酒或适量 / 未久坐超 1 小时 / 按计划执行不拖延 |

## 状态判定

| 完成率 | 状态 |
|------|------|
| ≥ 90% | 自律达人 |
| 75–89% | 状态良好 |
| 60–74% | 及格线上 |
| < 60% | 需要加强 |

纪律底线任一项未完成，报告中额外标注「⚠ 底线未守」。

## 用法

```bash
# 1. 交互式打卡
python3 scripts/fitness.py check

# 2. 直接传已完成项
python3 scripts/fitness.py check --done f1,f2,f3,f4,f5,f8,f9,f13,f14,f15

# 3. 生成今日报告
python3 scripts/fitness.py report

# 4. 查看多日趋势
python3 scripts/fitness.py trend

# 5. 一句话摘要
python3 scripts/fitness.py summary
```

打卡记录默认保存到 `~/.fitness-daily.csv`（可用 `--log` 指定其他文件），每天一行、可跨天积累看趋势。
