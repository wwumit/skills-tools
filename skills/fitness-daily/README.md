# 🏋️ Fitness Daily — 30 岁青年健身自律打卡

> 纪律类 · 非认证众包 — 一位 30 岁青年把坚持多年的每日健身习惯固化并共享出来。

## 这是什么

一张可勾选的每日健身清单，四组 15 项。勾选今天做到的事 → 完成率 → 状态判定 → 下周重点建议。
把项目换成「学习计划 / 团队代码纪律 / 销售 SOP」，就是另一条 Skill——规则引擎完全一样。

## 快速开始

```bash
# 交互式打卡（逐项 y/n）
python3 scripts/fitness.py check

# 直接传已完成项
python3 scripts/fitness.py check --done f1,f2,f3,f4,f5,f8,f9,f13,f14,f15

# 今日报告
python3 scripts/fitness.py report

# 多日趋势
python3 scripts/fitness.py trend

# 一句话摘要
python3 scripts/fitness.py summary
```

## 四组十五项

| 组 | 项 | 示例 |
|------|------|------|
| 身体活动 | f1–f3 | 30 分钟中高强度运动 / 步数≥8000 / 拉伸 10 分钟 |
| 营养与恢复 | f4–f8 | 饮水≥2升 / 蛋白质达标 / 蔬菜占一半 / 无深夜进食 / 睡眠 7–9 小时 |
| 心理与习惯 | f9–f12 | 冥想 5 分钟 / 屏幕时间≤2小时 / 健康日志 / 阅读 15 分钟 |
| 纪律底线 | f13–f15 | 未饮酒或适量 / 未久坐超 1 小时 / 按计划执行不拖延 |

## 数据

打卡记录默认保存到 `~/.fitness-daily.csv`，每天一行、可跨天积累看趋势。可用 `--log <文件>` 指定其他记录文件。
