# Changelog
## 1.3.1 (2026-07-20)

- **法规体系持续扩展**：新增 5 条规则，从 43 条扩展到 48 条，参考来源从 27 个增加到 32 个
- **新增 PRI-004 儿童个人信息保护**：基于《儿童个人信息网络保护规定》（2019），检查面向儿童技能的特殊保护声明
- **新增 PRI-005 个人信息安全影响评估**：基于GB/T 39335-2020《个人信息安全影响评估指南》，检查PIA评估声明
- **新增 PRI-006 违规收集个人信息认定**：基于《APP违法违规收集使用个人信息行为认定方法》（2019），检查默认同意、捆绑授权等违规模式
- **新增 REG-015 消费者权益保护合规**：基于《消费者权益保护法》（2014），检查收费技能的消费者权益声明
- **新增 REG-016 用户账号信息管理合规**：基于《互联网用户账号信息管理规定》（2022），检查注册/登录功能的信息核验声明

## 1.3.0 (2026-07-20)

- **法规体系扩展**：新增 5 条规则，从 38 条扩展到 43 条，参考来源从 22 个增加到 27 个
- **新增 FIN-006 金融信息服务合规**：基于《金融信息服务管理规定》（2019），检测技能是否声明金融信息服务资质和风险提示
- **新增 EXA-004 广告标识合规**：基于《互联网广告管理办法》（2023），检测广告性质描述是否进行广告标识
- **新增 REG-012 网络数据安全管理合规**：基于《网络数据安全管理条例》（2025年1月1日施行），检测数据安全管理制度声明
- **新增 REG-013 电子商务平台合规**：基于《电子商务法》（2019），检测交易/平台功能声明与合规主体信息
- **新增 REG-014 网络信息内容生态治理**：基于《网络信息内容生态治理规定》（2020），检测内容生成类技能的内容安全审核机制

## 1.2.0 (2026-07-20)

- **安全扫描体系升级**：新增 7 条规则，从 31 条扩展到 38 条，覆盖 11 个检查类别
- **新增 SEC-005 外部脚本获取**：检测 curl|bash、wget|sh 等运行时外部代码获取模式
- **新增 SEC-006 代码混淆**：检测 base64/hex 解码执行、混淆绕过模式
- **新增 SEC-007 MCP权限过度声明**：检测通配符权限（*）、未声明能力范围的高风险 MCP 配置
- **新增 SEC-008 输出处理安全**：检测未验证输出注入、跨上下文输出、文件写入安全风险
- **新增 REG-010 数据安全法合规**：基于《数据安全法》2021年9月1日施行，检测数据分类分级、数据安全保护义务
- **新增 REG-011 关键信息基础设施保护**：基于《关基保护条例》2021年9月1日施行
- **新增 ADVISORY 建议性告警类别**：独立于法律合规评分之外，不影响 PASS/REJECT 判定
- **新增 check_description_mismatch**：智能检测 SKILL.md 声明与实际代码行为不一致（如声称 network:none 但含网络调用），自动排除合规工具自身的模式串
- **改进评分输出**：新增【平台告警】双轨制显示，法律合规与平台规范分开呈现
- **新增 rule_groups**：cn_strict（33条规则）和 cn_standard（20条规则）两种模式
- **法律依据审计**：sources.references 新增《数据安全法》《关基保护条例》、OWASP、NIST 等引用


## 1.1.0 (2026-07-19)

- **法规依据审计**：全部 31 条规则的 `legal_source` 字段逐条核查并修正
  - 修正法规名称错误：DISC-001 原引《证券投资咨询管理暂行办法》→ 更正为《证券、期货投资咨询管理暂行办法》
  - 修正条款引用错误：REG-004 原引《未成年人保护法》第76条（网络直播专用条款）→ 更正为《未成年人网络保护条例》（2024年施行）
  - 修正条款理解错误：REG-005 原引《互联网诊疗管理办法（试行）》第4条（允许性条款）→ 更正为《医疗机构管理条例》第23条（禁止无资质行医）
  - 修正引用不完整：REG-003 新增《算法推荐管理规定》第24条备案时限
  - 补充施行日期：15 条规则的 legal_source 新增了法规公布/施行日期（如《个人信息保护法》2021年11月1日施行）
  - 补充发布机关：REG-006（双减）标注中央/国办联合印发；REG-007（代币）标注七部委联合发布
  - 新增 `sources.references` 字段，收录 18 项法规的发布日期、施行日期和发布机关信息，方便后续交叉核对
- **误报修复（第二批）**：
  - REG-003：不再把"RECOMMENDATIONS"节标题算作算法推荐
  - FIN-003：不再把"数据分析/技术分析/合规检查"等工具名算作需资质用语
- **扩展规则库**：从 19 条规则增加到 31 条规则
- **新增类别**：
  - PRIVACY — 数据隐私合规（个人信息收集声明、用户同意机制、数据出境合规），基于《个人信息保护法》
  - REGULATORY — 专项监管合规（ICP备案、AIGC标识、算法备案、未成年人保护、医疗卫生红线、虚拟资产红线、教育培训合规、等保、反不正当竞争）
- **修复**：EXA-001 对"第三方数据/服务/平台"等合规术语的误报
- **评分改进**：
  - PASS / NEEDS_FIX / REJECT 阈值调整为 ≥70 / 40–69 / <40（实际代码已采用该阈值，现在 SKILL.md 文档对齐）
  - PRIVACY/REGULATORY 交叉建议集成到 check_recommendations
  - redline 一票否决制在评分和结论中明确体现
- **新增子命令**：check 全面检查现涵盖 PRIVACY 和 REGULATORY 扫描

## 1.0.0 (2026-07-19)

- 初始发布
- 五大检查模块：
  - FINANCE — 敏感金融用语检查（荐股/投资建议/保证收益/需资质用语）
  - DISCLAIMER — 免责声明检查（投资/法律声明位置与内容）
  - EXAGGERATION — 极限词与夸大描述检查
  - SECURITY — 安全红线（subprocess/exec/eval/JSON/版本号）
  - RECOMMENDATIONS — 改进建议
- 四个子命令：check / disclaimer / keywords / summary
- 文本和 JSON 两种输出格式
- 综合评分系统（0–100）与评估结论（PASS / NEEDS_FIX / REJECT）
- 批量扫描多 skill 目录并排序
- 纯 Python 标准库，零外部依赖，无网络请求
